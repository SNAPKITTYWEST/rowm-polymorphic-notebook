CORE FUNCTIONALITY
================================================================================

REAL INFERENCE
- Model inference runs locally in browser
- WebGPU acceleration when available (CPU fallback)
- Streaming tokens via MLCEngine.chat.completions.create()
- Supported models: Llama 2 7B, Mistral 7B, NeuralHermes 7B, TinyLlama 1.1B

NOTEBOOK INTEGRATION
- Extracts notebook cells from DOM
- Builds searchable keyword index
- Finds relevant cells for user queries
- Includes cell content in system prompt
- Cites cell references in responses

USER INTERFACE
- Ω launcher button (60px fixed bottom-right, pulsing cyan)
- Chat panel (430×650px, draggable, minimizable)
- Real-time token display (streaming)
- Status tracking (OFFLINE → LOADING → READY → GENERATING)
- Send/Stop/Clear controls
- Message history (last 8 messages for context)
- Mobile responsive (95vw on <480px)

DESIGN
- Dark sovereign theme (navy/cyan/gold)
- Smooth animations (slide, pulse, glow)
- Accessible color contrast (WCAG AA+)
- Clean typography and spacing

================================================================================
ARCHITECTURE
================================================================================

NotebookPageReader
  └─ extractCells() → [{id, index, type, source, output, hash}, ...]
  └─ getNotebookMetadata() → {title, subtitle, cellCount, timestamp}

NotebookContextIndex
  ├─ rebuild() → Refresh from notebook
  ├─ findRelevant(query, limit) → Ranked cells
  ├─ getCellByIndex(index) → Cell
  └─ formatContextAsText(cells) → String

AhmadWebLLMEngine
  ├─ initialize(modelId) → Download + load model
  ├─ generate(userMessage, systemPrompt) → Stream tokens
  ├─ buildSystemPrompt(userMessage) → Include notebook context
  ├─ isReady() → Boolean
  ├─ interrupt() → Stop generation
  └─ on(event, callback) → Event listener

AhmadBotUI
  ├─ openPanel() → Show interface
  ├─ closePanel() → Hide interface
  ├─ sendMessage() → Submit user input
  ├─ stopGeneration() → Interrupt model
  ├─ clearMessages() → Empty chat
  ├─ updateStatus(status) → Update badge
  └─ appendToken(token) → Display token stream

TROUBLESHOOTING
================================================================================

See AHMAD_BOT_GUIDE.md → Troubleshooting section for:
  • Model won't initialize
  • Downloads slowly
  • GPU not used
  • Unicode not preserved
  • Responses cut off
  • Browser compatibility issues

Common Solutions:
  → Clear browser cache and reload
  → Check console for errors (F12 → Console)
  → Verify WebLLM loaded (console.log(window.webllm))
  → Try smaller model (TinyLlama) first
  → Check internet connection
  → Ensure 8GB+ RAM for 7B models
